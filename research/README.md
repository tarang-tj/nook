# Research

Notes on things we read or tested go here: documentation, articles, other products, measurements we took ourselves. One file per topic. For anything from outside, include the link and the date you read it, and quote the part you are relying on. For anything we measured, say who measured it, how, and with what. If you could not find a source for a claim, write it as a question in [docs/open-questions.md](../docs/open-questions.md) instead.

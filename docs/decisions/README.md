# Decisions

No decisions are recorded yet.

When the team decides something, add one file here so it does not get lost in a chat thread.

- One decision per file.
- Name it with the date and a few words: `2026-10-14-capture-method.md`.
- Keep it short. Half a page is plenty.

Each file answers four things:

```markdown
# What we decided (one line)

Date: 2026-10-14
In the room: who took part in the decision

## What
The decision, in plain words.

## Why
The reasons, and the options we turned down.
```

If a decision changes later, do not edit the old file. Add a new one and link back to the old one.
